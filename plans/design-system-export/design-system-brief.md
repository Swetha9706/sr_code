# Swetha's Design Studio — design system brief

Source: this project (`Moodboard v3.dc.html`, `Case Study Section.dc.html`, `Journey Map.dc.html`, `uploads/LondrinaSolid-Regular.otf`).

## Decisions
- Name: Swetha's Design Studio
- Headings: H1 + H2 Bricolage Grotesque 700 (tight tracking). Londrina Solid for display, stats, stickers, wordmark only. Labels JetBrains Mono.
- Icons: Unicode only (↗ → ← ↑ ✦ ✓ •). No icon library.
- Themes: full light / dark toggle (cocoa dark theme; every semantic token swaps).
- Voice: follow the plainer-voice skill (direct, plainspoken, full sentences, no restatement, hedges kept).
- No logo: wordmark is plain Londrina text.

Button, Link, Tag / pill, Sticker, Project card, Stat callout + Stat list, Quote, Insight panel, Nav bar, Footer, Input / form, Journey map parts (lane, stage, emotion tag, emotion chart).
